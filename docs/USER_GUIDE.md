# 普通使用者指南

## 当前版本与安装

L-BOT `0.2.0` 是开发验收版本。默认打开**手动／模拟消息通道**，没有登录你的个人社交账号。林夏、项目讨论、家人是示例会话，固定示例草稿不是 AI 推理。审核、复制均不代表平台已接收。

Android 安装 `L-BOT-Android-0.2.0-arm64-debug.apk`，需 arm64 设备，安装时由你允许文件管理器安装应用。这是调试签名包；8GB 物理 RAM 为目标，尚待实机验证。

Windows 安装 `L-BOT-Setup-0.2.0-x64.exe`，按向导安装至当前用户的应用目录。缺少 Visual C++ x64 运行库时，安装器先核验 Microsoft 签名与固定 SHA，再通过正常 Windows UAC 请求安装。包尚未签名，系统可能显示未识别发布者，请核对交付来源与校验值。可从托盘打开、暂停、退出，首次配置无需命令行。

## 本地模型

在“本地模型”查看当前平台的默认模型：

| 平台 | 模型与下载量 | 资源准备 |
| --- | --- | --- |
| Android | HauhauCS Qwen3.5-2B Q4_K_M，约 **1.27 GB** | 建议至少 **3 GB** 存储余量；8GB 物理 RAM 目标仍待实机验证 |
| Windows | HauhauCS Qwen3.5-9B Q4_K_M，约 **5.63 GB** | 建议至少 **16 GiB** 物理内存及 **8.5 GB** 存储余量；这是资源建议，未构成 Windows 设备性能验收 |

点击下载，通过固定版本 SHA-256 校验后加载；失败要查看错误，不算已启用。两端默认完整有效上下文均为 **12,800 tokens**，使用应用内置原生 CPU 引擎，不需 Python 或另装服务器。手机 2B 模型及哈希保持不变。

模型准备好后文字推理可离线运行；首次下载制品不等于上传聊天。不用时停止释放，删除不会上传数据。

文件分别来自 `HauhauCS/Qwen3.5-2B-Uncensored-HauhauCS-Aggressive` 与 `HauhauCS/Qwen3.5-9B-Uncensored-HauhauCS-Aggressive`，Q4_K_M 是社区版本，原版来自 Qwen。上轮 2B 的 Linux 云机文字、近满上下文、视觉和语音功能验证已完成；9B 的制品及运行另行记录。真实 Android／Windows 设备仍需独立验证，不能将云机或 2B 结果当作 9B、手机验收。

本地图片和语音路径已实现。在“本地模型”安装当前默认模型的匹配视觉组件：Android 2B 约 **668 MB**，Windows 9B 约 **922 MB**；语音共用约 **148 MB** 的 Whisper Base 多语言模型。分别下载并校验，2B 与 9B projector 不混用。组件准备好后可在本机处理，具体设备与质量记录见验收记录。缺少组件时停止，不静默上传，也不把人工描述或 OCR 冒充语义理解。

## DeepSeek、豆包、千问与自定义 API

1. 打开“自定义 API”，选择预设或新增配置。
2. 填地址、实际模型 ID、完整上下文、最大输出、温度、超时。豆包填写账号实际可用的模型 ID／接入点 ID。
3. 在 API Key 字段输入密钥并保存到本机安全存储。不要把密钥放在 URL、普通请求头或额外参数。
4. 获取模型列表或发送固定测试消息。服务不提供列表时可手动填写。401 为鉴权失败，403 为权限拒绝，429 为限流。
5. 按服务文档勾选文字、图片、转写能力；支持文字不等于支持多模态。
6. 消息中心选择 API 模式，明确勾选允许本次内容上传。没有授权不会传送聊天；本地失败也不会自动回退到 API。

可编辑预设：DeepSeek `https://api.deepseek.com/v1`，豆包 `https://ark.cn-beijing.volces.com/api/v3`，千问 `https://dashscope.aliyuncs.com/compatible-mode/v1`。地域、版本和模型能力以服务当前文档为准。本期无付费服务凭据，适配器测试不代表供应商联调成功。

公网使用 HTTPS；HTTP 仅用于信任的本机／局域网。混合模式允许文字生成、图片理解、语音识别分别选择本机或当前 API，默认三项均在本机；API 模式使用所选服务。任何外部处理均需明确上传授权，集成状态以验收记录为准。

## 个人表达与记忆

“我的表达”填写基调、常用词、句长、标点、拒绝方式、关系差异及判断原则。保存后下一次生成使用新档案。写明时间不确定先追问、哪些事情不能自行承诺。

填写“收到—理想回复—原因”并本人确认后加入检索。聊天导入必须选本人 authorId，只学习本人回复；导入私聊示例默认隔离。草稿的“像我／不像我”仅记录反馈，只有明确确认的理想回复才加入示例。版本可回滚，**这些操作不是模型微调**。

联系人记忆默认仅用于该账号／会话；本人勾选共享才跨会话。记录来源与确认，支持修改、设置有效天数、立即失效和删除。过期记忆不会进入回复；不把对方猜测或 AI 推断当作本人事实。

## 消息、审核与接管

选择会话，粘贴收到的消息，“添加消息”后生成。当前手动通道不读取其他软件。

图片／音频单个上限 5 MB，一次一个附件。图片原始不超过400万像素，本机缩至最长边1280；音频最长60秒，本机转换为16kHz单声道WAV。主动麦克风仅在你点击允许后录音，最长 60 秒，再点停止，不自动上传。转写应检查并修正。媒体原文件只保留本次内存，重启后尚未处理的附件需重新导入，已确认的分析／转写随状态保存；占位文字不代表处理成功。

添加附件消息后，点击原消息下的“理解这张图片”或“转写这条语音”。结果与原消息并列显示，先检查或修改“附件处理结果”，再点“修正并确认”，然后生成文字回复。原消息保持不变，分析和转写不会自动成为本人事实或正确训练示例。本地处理按阶段释放组件，再进行文字生成。

支付、密码、验证码、隐私、重要承诺与未确认的图片／转写进入审核。暂停阻止发送，接管取消此会话旧草稿。生成中收到新消息、暂停、接管或修改表达偏好／记忆时丢弃旧结果；偏好和记忆修改也会取消尚未发送的旧草稿，可对同一条消息重新生成。

当前真实发送权限未开放，可复制到原社交软件自行发送。自动模式需要真实连接器、明确范围授权与单一负责人。

## 数据与限制

“运行与数据”支持加密导出／导入，口令至少 12 字符。Android 选择系统保存位置，Windows 使用文件下载保存；文件只有加密内容。跨设备配置正文上限16 MiB，导入信封上限32 MiB，过大时先清理历史。正文默认保留30天，可改7／30／90／365天，未决发送原文保留至核实，无正文去重标识仍保留。密钥不导出；导入后暂停并关闭自动发送，重新录入 API Key。错误口令不替换现有数据。

可以删除聊天、队列、记忆与日志，日志省略正文及密钥。浏览器只保存内存，刷新清空；原生安全存储不可用时提示失败，不降级明文。读取既有安全数据失败时，本次更改仅在内存，保留原文件，避免用默认状态覆盖旧数据。

锁屏、后台、热、省电、网络切换及 30 分钟稳定性仍待实机测试。不能依赖系统杀死进程后持续回复；不要同时在两设备自动发送同一真实账号。
