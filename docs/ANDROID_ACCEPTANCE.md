## 功能与隐私验收

- 自定义 API 真正可配置并产生服务响应，密钥不泄漏。
- 修改本人偏好后回复变化；修改、删除、回滚有效。
- 不同账号／联系人／群聊信息和导入示例隔离。
- 重复平台事件只处理一次；未知结果不盲重发。
- 暂停阻止待发送；接管取消旧草稿；上下文变化丢弃旧结果。
- 本地模式抓取实际网络证据，聊天、图片、语音不传外部模型。
- 图片／音频处理与原消息对应，含不清楚内容的审核。
- 实際平台权限与文档一致；模拟通道不算真实联调。
