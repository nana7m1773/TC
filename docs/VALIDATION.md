当前交付为 **0.3.0 开发测试版**；以下分版本保留证据。记录区分源码／构建、Linux 云机功能验证、目标设备实测及真实社交平台联调。没有用模拟数据替代真实模型，也没有用云机替代 8GB 手机。

## 0.3.0 可用性修复（2026-10-15）

此次修复针对真实接入缺失、风格试用入口和过严的 Windows 窗口限制。

- Windows 新增各平台隔离的官方网页登录窗口与本机客户端唤起；QQ 使用本机客户端。打开窗口只代表窗口创建，登录仍由官方界面和账号决定。
- Android 新增系统 NotificationListenerService、包可见性、通知权限设置、已安装应用检测和 RemoteInput 原始通知回复。通知只在内存保存；没有回复动作时提供草稿复制。每个应用的前台自动回复默认关闭，离页、后台和暂停撤销。未实现持续后台 AI 服务。
- 桌面界面接入允许本人选择多个输入框和发送方式；允许前台 UIA，增加受目标窗口和焦点约束的单行 Unicode 输入。窗口签名作为提示，保留所有者、进程身份、快照和单次凭证核验。
- “我的表达”可直接进入风格试用，显示引用样本。生成保留已加载自定义模型的路径与实际上下文，避免误换默认模型或请求超过实际窗口。
- 原生发送前持久化预留；调用后结果未知只暂停相应会话，记录本人核实依据后恢复。已知未调用原生的失败可修复后重新审核；未知结果禁止自动重试。

## 保持待验收的项目

- **8GB Android 实机**：型号、SoC、Android、测试前可用内存、实际上下文、峰值内存、首响应、速度、温度和至少 30 分钟连续交互，全部待实际设备记录。
- **Android 系统行为**：SAF／安全存储／录音、锁屏、前后台、省电、系统回收、网络切换、热与低电等运行结果。
- **Windows 设备**：安装／卸载、Microsoft 签名与 UAC 前置安装、DPAPI、托盘、开机启动、实际本地文字／视觉／语音。安装器未签名；语音官方 CPU 包需 AVX2/FMA/F16C，具体 CPU 兼容性须验证。
- **API 服务联调**：三家中国服务预设和通用协议通过测试；当前环境未设置 DEEPSEEK_API_KEY、ARK_API_KEY、DASHSCOPE_API_KEY，也没有对应安全绑定。没有宣称付费服务真实调用成功，使用者在应用中安全配置。
- **真实平台与自动发送**：QQ 模块仅解析官方独立机器人事件和规划被动回复，未实现／验证完整实时传输接入；本人 QQ、微信及其他个人账号的目标权限按能力表保留缺口。当前增加实验性Windows选窗一次输入／Invoke路径，真实客户端尚未验收，缺少常驻可靠消息监听。
- **多设备／后台**：没有可靠跨设备租约与 Android 持续后台机制，不能保证系统终止进程后持续回复，也不能同时启用同账号两设备自动发送。
- **媒体留存**：原始消息、分析和修正关联到消息 ID，正文加密保留；导入媒体字节目前只在本次内存，重启后未处理的附件需重新导入。

自动模式和完整实机与真实平台需求尚未正式验收。设备验收表见 ANDROID_ACCEPTANCE.md，平台权限见 PLATFORM_CAPABILITIES.md；没有以扫码按钮、通知、机器人或 mock 代替个人聊天接管。
